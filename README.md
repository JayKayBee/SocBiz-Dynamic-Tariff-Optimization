# SocBiz-Dynamic-Tariff-Optimization
Agentic AI system for dynamic EV charging tariffs. Forecasts station demand (HistGBR + lag features) and sets adaptive surge/discount pricing on 3M+ records from Caltech ACN and Shenzhen ST-EVCDP. +3.66% revenue vs flat tariff; dynamic stations show 34.9% higher utilization.
